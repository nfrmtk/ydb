* Индекс всегда [локальный](../../../../concepts/glossary.md#local-index) (`LOCAL`); глобального варианта нет.
* Поддерживается только для [колоночных таблиц](../../../../concepts/datamodel/table.md#column-oriented-tables). Создание на строковой таблице будет отклонено.
* В одном `min_max` индексе индексируется ровно одна колонка — несколько колонок в `ON (...)` не поддерживается.
* Секция `COVER (...)` и дополнительные колонки индекса не поддерживаются.
* Настраиваемых параметров нет — секция `WITH (...)` не используется.
* В запросах не используется синтаксис `VIEW <index_name>`: пропуск фрагментов происходит автоматически в слое хранения при чтении основной таблицы.
* Изменение параметров индекса после создания не поддерживается — индекс нужно удалить и пересоздать.
* Фильтр применяется только к тем фрагментам данных, для которых индекс был построен на момент записи или перестройки. Для остальных фрагментов пропуск не выполняется до пересборки порции.
