Индекс пропуска по минимуму/максимуму хранит для каждого фрагмента данных минимальное и максимальное значения индексируемой колонки. При чтении таблицы фрагменты, где запрошенное значение или диапазон выходят за пределы интервала `[min, max]`, пропускаются без чтения колоночных данных — это сокращает объём фактически считываемых данных при селективных запросах.
