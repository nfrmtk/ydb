min_max индекс хранит для каждого фрагмента данных минимальное и максимальное значения индексируемой колонки. При чтении таблицы фрагменты, где запрошенное значение или диапазон не пересекаются с отрезком `[min, max]`, пропускаются без чтения колоночных данных — это сокращает объём фактически считываемых данных в запросах с высокоселективными фильтрами.
